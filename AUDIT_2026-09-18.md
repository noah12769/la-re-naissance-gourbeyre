## Erreurs importantes

1. **Espace admin = aperçu non sécurisé, accessible publiquement.** `connexion.html` vérifie le mot de passe (`1234`) **dans le navigateur** : n'importe qui peut le lire dans le code. Aujourd'hui c'est sans conséquence (l'admin n'écrit rien sur le site : les modifications restent dans le `localStorage` du visiteur, et la page l'annonce clairement par un bandeau « Mode aperçu »), mais :
   - le lien « Connexion » du footer est public ;
   - **ce mot de passe ne doit jamais protéger une écriture réelle.** Avant de brancher l'admin au site (Supabase), le remplacer par une vraie authentification (Supabase Auth) + règles d'accès côté base (RLS), et mettre à jour la CSP de `vercel.json` (`connect-src` / `img-src` pour le domaine Supabase).
   - Les deux pages sont en `noindex, nofollow` (elles n'apparaîtront pas dans Google).
   - Rappel README : c'est documenté.
2. **Photo de groupe : ancien numéro de téléphone visible sur la banderole** (« 0690 64 33 41 »). Idem sur plusieurs autres photos de la galerie. Ce n'est pas un défaut technique mais un point de cohérence : le site affiche 0690 90 24 20 / 0590 46 85 85. À signaler au restaurant.

## Recommandations

3. **CLS entre 0,09 et 0,13 (cible < 0,1), déjà présent avant les changements du jour** (mesuré 0,111 avant → 0,087–0,131 après, selon la bande passante simulée). Cause identifiée par les entrées `layout-shift` : au chargement des polices Karantina/DM Sans (WebFontLoader), le titre du hero et la barre de navigation se recalent. Pistes : héberger les polices en local (`/assets/fonts`) avec `<link rel="preload">` + `font-display: swap` + `size-adjust`, ou masquer le titre jusqu'à `wf-active`. Non bloquant.
4. **Pas de repère `<main>`** sur `index.html` (axe : `landmark-one-main` + `region`, gravité *modérée*). Le contenu est composé de blocs `sticky` Webflow ; envelopper le tout dans `<main>` demande un test visuel complet du défilement. Non appliqué par prudence — à faire dans une session dédiée.
5. **Google Maps intégrée = cookies Google.** Le site n'a pas de bannière de consentement. Si la CNIL est un sujet pour le client : remplacer l'iframe par un bouton « Afficher la carte » (chargement au clic) ou ajouter une bannière. Mentionné dans `confidentialite.html`.
6. **Droit à l'image.** La galerie montre des clients. Le restaurant doit disposer de leur accord ; à formaliser avant d'ouvrir l'ajout de photos par l'admin (voir aussi `confidentialite.html`).
7. **Image du hero desktop = 383 Ko**, la plus lourde du site. Une version 1600 px / qualité 78 gagnerait ~30 % (le LCP mesuré est déjà bon : 0,8–1,1 s en local).
8. **Analytics** : seul Vercel Analytics tourne. Google Search Console (à créer côté compte, ajouter le sitemap `https://la-re-naissance.com/sitemap.xml`), Google Analytics et Pixel Meta restent à configurer si le client les veut. **Fiche Google Business Profile** : à vérifier que l'adresse est bien « Rue Charles Borome » (comme sur le site) et que le lien du site est renseigné.
9. **Deux images inutilisées** dans `assets/images/` : `favicon-256.webp`, `qr-partage.webp` (peut-être prévues pour l'impression). Conservées, à supprimer si elles sont vraiment mortes.
10. **Pas de `.env.example`** : volontaire — le site ne lit aucune variable d'environnement (voir README). À créer dès l'arrivée de Supabase (`SUPABASE_URL`, `SUPABASE_ANON_KEY`).
11. **Titre de section** « Souvenir » / hero : la phrase d'accroche du hero (« Une table chaleureuse à Gourbeyre… ») est **provisoire** — le client a demandé 5 nouvelles propositions. À remplacer dès qu'il en a choisi une.

## Ce qui a été vérifié et est bon

- **Responsive** : 0 px de débordement horizontal, 0 image cassée, 0 erreur JS/console sur 9 tailles × 4 pages (seuls les `_vercel/*` 404 en local, normal).
- **Performance (local, réseau bridé)** : LCP 0,8 s (mobile) / 0,9–1,1 s (desktop) < 2,5 s ; CLS mobile 0 ; poids initial 2,3 Mo ; `srcset` (500/800/plein) partout.
- **SEO technique** : `title` unique, meta description, canonical (`la-re-naissance.com`), Open Graph + Twitter Cards complets, JSON-LD `Restaurant` à jour, un seul `<h1>`, `lang="fr"`, `robots.txt` + `sitemap.xml` cohérents ; pages légales, connexion et admin en `noindex`.
- **SEO local** : nom, téléphone, email, adresse, horaires (midi mar–dim sauf sam ; soir ven–sam), Instagram — cohérents entre page, JSON-LD, `llms.txt`.
- **Accessibilité (axe-core, 5 pages)** : plus aucune violation *serious/critical* après corrections ; reste `<main>` (recommandation 4). Navigation clavier du menu mobile, pop-up et admin OK.
- **Sécurité** : aucun secret dans le dépôt ni dans l'historique (`.env.local` ignoré, jamais commité) ; HSTS, CSP, X-Frame-Options, nosniff, Referrer-Policy, Permissions-Policy actifs ; aucune donnée saisie par les visiteurs ; liens externes en `rel="noopener"`.
- **Formulaires** : aucun formulaire public (le seul champ est le mot de passe de l'aperçu admin).
- **RGPD** : mentions légales complètes (éditeur, SIREN/SIRET/APE/TVA, gérants, hébergeur, contact) ; politique de confidentialité cohérente avec le fonctionnement actuel.
- **`llms.txt`** : présent et synchronisé.
